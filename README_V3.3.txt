JG Mobile Mechanic V3.3

NEW
- Job workflow status: Request Received, Booked, In Progress, Waiting for Parts, Completed, Collected.
- Mechanic can set/update job status on New Job / Edit Job.
- Customer portal shows the current status of each job in Service History.
- Records screen shows job status plus payment status.

INSTALL / UPDATE
1. In Supabase SQL Editor, run upgrade_v3_3.sql once.
2. Replace your current app files with this V3.3 package.
3. Sign in as mechanic and edit/create a job to test the status.
4. Sign in as the linked customer and check Service History.

Next planned version: Android push notifications.
