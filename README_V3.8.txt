JG Mobile Mechanic Cloud Edition V3.8

Customer portal improvements:
- Customer invoices are clickable and open a full invoice detail view.
- Invoice detail includes vehicle, description, parts, labour, total, payment status and Print / Save PDF.
- Service / Job Records are clickable for customers.
- Job detail shows reported fault, diagnosis, work carried out, parts fitted, status and mileage.
- Job progress photos are displayed from the existing job-photos storage bucket.
- Request Service / Repair now shows previous work for the selected vehicle, with clickable job details.

Deployment:
1. Run upgrade_v3_8.sql in Supabase SQL Editor once.
2. Upload the web files to the GitHub Pages repository as usual.
3. Refresh app.jgmechanic.co.uk and verify Cloud Edition V3.8.

Existing notification/Firebase code is retained.
